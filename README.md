# OSINT-Investigation-Report
An OSINT Investigation Report of three challenges provided in the TCMS discord server and a blog post that can be found [here](https://tcm-sec.com/how-to-pass-the-porp-certification-exam/). To be used as an example of an OSINT report. 

This report is a modified version of the template provided by TCM Security themselves here: https://github.com/TCM-Security/osint. The changes that have been made to the template are mostly stylistic. On top of that though, all of the challenges given as examples are different from the ones used within the orginal report. Feel free to use this as a template for your own reports, making any modifications you wish.
